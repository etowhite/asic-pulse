# ASIC Pulse 1.1 — Material You BTC Tools

Копия проекта ASIC Pulse с расширенным набором функций управления ASIC-майнерами.

## Новое в версии 1.1

- **Точная настройка частоты (MHz) и напряжения** — в окне «Режим питания».
  Для Antminer конфиг читается целиком и возвращается с изменённой частотой, чтобы не сбросить пулы.
  Для WhatsMiner используется API `set.miner.freq` (порт 4028), для Avalon — `ascset`.
- **Сложность пула (diff)** — необязательное поле в окне «Настройка пулов». Пустое значение означает автосложность.
- **Экран «Инструменты»**:
  - калькулятор доходности по хешрейту, потреблению, тарифу, комиссии пула и курсу BTC;
  - автоподстановка данных парка;
  - статистика сети Bitcoin с mempool.space: курс, хешрейт, сложность, высота блока, награда и обратный отсчёт до халвинга.
- **Импорт диапазонов IP из файла CSV/TXT** в дополнение к вставке текста.

## Сборка

```powershell
cd src-tauri
cargo build --release
```

Готовый файл: `src-tauri\target\release\asic-pulse-m3.exe`.

## Запуск без сборки

Для просмотра интерфейса можно открыть `src/index.html` через локальный HTTP-сервер:

```powershell
cd src
python -m http.server 8765
```

и перейти на `http://127.0.0.1:8765/`.
